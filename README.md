# Fundamentals-of-RAG
# RAG From Scratch

This repository contains my complete learning journey of Retrieval-Augmented Generation (RAG), starting from the fundamentals and progressing to production-ready RAG systems.

The goal of this repository is to understand **how RAG works internally**, rather than only using high-level frameworks.

## Topics Covered

- Introduction to RAG
- RAG Architecture
- Indexing Pipeline
- Document Loading
- Chunking
- Embeddings
- Vector Databases
- Similarity Search
- Retriever
- Prompt Construction
- LLM Generation
- Complete RAG Pipeline
- Advanced RAG
- GraphRAG
- Projects

## Learning Goal

By the end of this repository, we will understand:

- Why RAG was invented
- How documents become searchable
- How embeddings are created
- How vector databases work
- How relevant information is retrieved
- How LLMs generate answers using retrieved context
- How to build RAG systems from scratch using Python
